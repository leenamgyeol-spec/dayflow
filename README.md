# DAYFLOW

> 당신의 하루를 기억하고, 더 나은 하루를 설계합니다.

개인 AI 일정 비서 웹앱입니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

## 실행

```bash
python -m http.server 5530 --directory dayflow
```

브라우저에서 http://localhost:5530 을 엽니다. (알림·오프라인 기능은 `localhost` 또는 HTTPS에서만 동작하므로, `index.html`을 더블클릭해 여는 것보다 서버로 여는 것을 권장합니다.) GitHub Pages 같은 정적 호스팅에 폴더째 올려도 됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/time.js` | 한국 시간(Asia/Seoul) 기준 날짜·시간 계산 |
| `js/db.js` | IndexedDB 영구 저장 (안 되면 localStorage) |
| `js/store.js` | 일정 CRUD, 반복 일정, 충돌·중복 감지, 검색, 백업·가져오기·.ics |
| `js/nlp.js` | 한국어 자연어 일정 해석 |
| `js/brief.js` | 아침 브리핑, 오늘의 한마디, 통계, 미래 예측 |
| `js/chat.js` | AI 비서 대화와 저녁 마감 대화 |
| `js/notify.js` | 일정 알림, 브리핑 자동 실행 스케줄러 |
| `js/weather.js` | Open-Meteo 날씨 (API 키 불필요) |
| `js/ui.js`, `js/app.js` | 화면 |

## 데이터

- 모든 일정은 브라우저의 IndexedDB에 저장되어 새로고침·재시작 후에도 남습니다.
- 하루 한 번 자동 스냅샷(최근 7개)을 만들고, 설정 화면에서 복원할 수 있습니다.
- 설정 → 백업 내보내기(JSON) / 가져오기, 캘린더 내보내기(.ics)를 지원합니다.
- 데이터는 기기(브라우저)별로 저장됩니다. 다른 기기와 동기화하려면 서버 저장소가 필요합니다.

## 한계

- 자동 브리핑과 알림은 앱이 브라우저에 열려 있을 때(탭이 뒤에 있어도) 동작합니다. 앱을 늦게 열면 놓친 브리핑을 한 번 보여 줍니다. 앱이 완전히 닫혀 있을 때 푸시를 보내려면 푸시 서버가 필요합니다.
- AI 비서는 규칙 기반 한국어 해석기로 동작합니다(외부 AI API 없음, 오프라인 동작). 해석 결과는 항상 등록 전에 보여 주고 확인을 받습니다.
